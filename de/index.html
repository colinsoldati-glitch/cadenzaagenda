Warum Cadenza?

Zeit für Organisation könnte auch Zeit zum Musizieren sein.

Cadenza entstand aus einem einfachen Bedürfnis: die tägliche Organisation von Musikensembles erleichtern. Weniger verstreute Nachrichten, weniger Rückfragen und ein gemeinsamer Überblick über kommende Termine.

Vom Duo bis zum Kammerensemble: Musik verbindet. Cadenza hilft bei der Organisation.

Colin SoldatiGründer von Cadenza

Immer griffbereit

Ihr Ensemble in Ihrer Tasche.

Cadenza ist eine Web-App. Nutzen Sie sie im Browser oder fügen Sie sie Ihrem Home-Bildschirm hinzu.

iPhone / iPad

Öffnen Sie die App in Safari. Tippen Sie auf Teilen, dann Zum Home-Bildschirm und Hinzufügen.

Android

Öffnen Sie die App in Chrome. Wählen Sie im Menü App installieren oder Zum Startbildschirm hinzufügen.

Computer

Öffnen Sie die App im Browser. Falls verfügbar, verwenden Sie das Installationssymbol in der Adressleiste.

Häufig gestellte Fragen

Muss ich ein Konto erstellen?+

Nein. Erstellen Sie ein Ensemble oder treten Sie per Code oder Link bei und geben Sie Ihren Namen und Ihr Instrument ein.

Wie lade ich andere Musiker ein?+

Nutzen Sie Einladen in der App und teilen Sie den Link Ihres Ensembles.

Kann ich mehrere Geräte verwenden?+

Ja. Nutzen Sie im Bereich Ensemble die Profilübertragung. Der persönliche Link stellt Ihr Profil wieder her: teilen Sie ihn nicht öffentlich.

Wie erhalte ich Benachrichtigungen?+

Aktivieren Sie Benachrichtigungen in der App und erlauben Sie sie auf Ihrem Gerät. Auf iPhone und iPad muss Cadenza auf dem Home-Bildschirm installiert sein. Die Verfügbarkeit hängt von Browser und System ab.

Wie werden meine Daten verwendet?+

Die App synchronisiert Ensembleinformationen über Firebase und verwendet lokale Profilkennungen. Die Präsentationsseite lädt Firebase nicht und die Demo sendet keine Daten. Bei Datenschutzfragen kontaktieren Sie uns.

Wie melde ich ein Problem?+

Schreiben Sie an contact@cadenzaapp.ch und beschreiben Sie das Problem und Ihr Gerät.
